# Zara Frontend Challenge

> Technical frontend challenge — Mobile device catalog with 
> real-time search, product detail and shopping cart.

🚧 **Status: In Progress**

---

## ✨ Features

- 🔍 **Real-time search** — Filter devices as you type
- 📱 **Product catalog** — Mobile device listing with detail view
- 🛒 **Shopping cart** — Add devices by color and storage *(in progress)*

---

## 🛠 Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS

---

## 🚀 Run Locally

```bash
git clone https://github.com/j4mLoz/zara-challenge-frontend.git
cd zara-challenge-frontend
npm install
npm run dev
```
